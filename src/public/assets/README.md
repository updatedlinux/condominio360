# Assets estáticos - Condominio360

Los archivos en esta carpeta se sirven públicamente desde la raíz del sitio.

## Ubicación y URLs

| Carpeta | Ruta en la web | Uso |
|---------|----------------|-----|
| `assets/images/` | `/assets/images/` | Logos, ilustraciones, fotos |
| `assets/icons/` | `/assets/icons/` | Iconos adicionales |
| `assets/illustrations/` | `/assets/illustrations/` | Gráficos y dibujos |

**Ejemplo:** `assets/images/logo.png` → `https://tudominio.com/assets/images/logo.png`

## Logo

Logos actuales en uso:
- **`CONDOMINIO360-whitelogo.svg`** — Para fondos claros (header, hero, navbar)
- **`CONDOMINIO360-blacklogo.svg`** — Para fondos oscuros (footer, CTA naranja)

Se escalan con `h-10`/`h-9` y `max-w` para mantener proporción en distintos viewports.
